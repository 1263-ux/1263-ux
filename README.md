# 1263-ux

### AI application developer · Agent engineering · Knowledge engineering

I build practical AI systems around the parts that are easy to hand-wave:
workflows, evidence, deployment, and repeatable engineering.

My background is in Java full-stack application development. I am now moving
deeper into AI-native software development, especially the infrastructure and
habits that make agentic systems useful beyond a single demo.

## What I am focused on

- **Agent engineering** — long-running workflows, harnesses, reusable skills, and adapters
- **Knowledge engineering** — filesystem-first RAG workflows, evidence, human review, and recall
- **AI application engineering** — Java, Spring Boot, Vue, TypeScript, Docker, and Linux
- **Exploring** — AI × security, especially around agent execution, remote access, and trustworthy results

## How I like to build

- Start with a real problem, not a fashionable abstraction.
- Keep evidence and limitations visible.
- Prefer small, reusable tools over impressive-looking demos.
- Treat deployment, review, and failure handling as part of the product.

I am building in public as these ideas become clearer.
