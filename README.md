## 👋 关于我

我在做的，不只是“把大模型接进项目”。

我更关心 Agent 真正开始工作之后的问题：**工作流能不能持续、知识能不能追溯、部署能不能维护、结果能不能验证。**

目前正从 Java 全栈应用开发，深入到 AI Native Coding、Agent Engineering 和 Knowledge Engineering；同时从工程实践出发，探索 AI × 网络安全。
